⚠️ 常见问题速查
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q1: 编译时出现 "undefined reference to pcl::XXX"
    → 查看 PCL_QUICK_FIX.txt
    → 这是自定义点类型链接错误，已有完整解决方案

Q2: 运行时提示 "error while loading shared libraries: libdnn.so"
    → 查看 BUILD_SUCCESS.txt 中的"库路径依赖"部分
    → 确保使用 ./run.sh 运行（已设置LD_LIBRARY_PATH）

Q3: 找不到立体图像对
    → 查看 READY_TO_USE.md 中的"输入要求"部分
    → 确保文件命名为 *_left.* 和 *_right.*

Q4: 如何修改推理模式?
    → 编辑 config.yaml，修改 infer_mode 参数 (0-6)
    → 参考 READY_TO_USE.md 了解不同模式含义

Q5: 如何调整相机参数?
    → 查看 docs/INTEGRATION_GUIDE.md 中的"相机参数配置"
    → 修改 offline_perception_debug.cpp 中的内参

🔍 关键文件说明
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⭐ src/pcl_instantiations.cpp
   作用: 为自定义点类型 PointXYZRGBL 提供 PCL 模板显式实例化
   重要性: 没有这个文件会导致链接错误
   详情: 查看 SOLUTION_SUMMARY.txt

⭐ run.sh
   作用: 设置库路径并运行程序
   关键: export LD_LIBRARY_PATH 配置 HobotDNN 库路径
   用法: ./run.sh

⭐ config.yaml
   作用: 运行时配置参数
   内容: 推理模式、模型路径、检测阈值、性能优化参数
   修改后: 无需重新编译，直接运行即可

⭐ CMakeLists.txt
   作用: CMake 构建配置
   关键配置:
     - DEPS_ROOT: 依赖库路径
     - SOURCES: 所有源文件列表（包含 pcl_instantiations.cpp）
     - LINK_libs: 链接 HobotDNN 库
