🧐 问题分析
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 根本原因
   • PCL使用模板类实现过滤器功能
   • 模板类的实现在 .hpp 文件中
   • PCL库只预编译了内置点类型 (PointXYZ, PointXYZRGB等)
   • 自定义点类型 (PointXYZRGBL) 没有预编译实例

2. 为什么编译通过但链接失败？
   • 编译阶段: 头文件 (.h) 提供了类声明，编译器认为函数存在
   • 链接阶段: 链接器在 libpcl_filters.so 中找不到 PointXYZRGBL 的实例
   • 结果: undefined reference 错误

3. 触发条件
   • 使用了自定义点类型 (struct PointXYZRGBL)
   • 使用了PCL模板过滤器类 (VoxelGrid, PassThrough等)
   • 没有显式实例化这些模板类

C++模板实例化机制
──────────────────────────────────────────────────────────────────

1. 模板声明 (.h)
   template<typename T> class VoxelGrid { ... };
   ↓
   编译器知道类存在，但没有生成代码

2. 模板实现 (.hpp)
   template<typename T>
   void VoxelGrid<T>::applyFilter(...) { ... }
   ↓
   包含具体实现逻辑

3. 隐式实例化 (使用时)
   VoxelGrid<PointXYZ> filter;  // PointXYZ是内置类型
   ↓
   编译器自动生成 VoxelGrid<PointXYZ> 的代码
   ↓
   但PCL库已经包含了这个实例，直接链接即可

4. 显式实例化 (自定义类型)
   template class VoxelGrid<PointXYZRGBL>;
   ↓
   强制编译器生成 VoxelGrid<PointXYZRGBL> 的代码
   ↓
   代码编译进 pcl_instantiations.cpp.o
   ↓
   链接器能找到所需的函数实现


为什么分离到单独文件？
──────────────────────────────────────────────────────────────────

方案A: 在每个使用的 cpp 中包含 .hpp
  ❌ 每个文件都编译一次模板 → 编译慢
  ❌ 多个 .o 文件都包含相同代码 → 可执行文件大
  ❌ 修改一处需要重新编译多个文件

方案B: 创建独立的实例化文件 (推荐)
  ✅ 只编译一次 → 编译快
  ✅ 代码只在一个 .o 中 → 可执行文件小
  ✅ 集中管理，易于维护

🎓 知识要点
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 模板类实现必须在头文件中 (.hpp)
   原因: 编译器需要看到实现才能生成特定类型的代码

2. PCL库只包含常见类型的实例
   内置: PointXYZ, PointXYZI, PointXYZRGB, PointXYZRGBA, PointNormal...
   自定义: 需要手动实例化

3. 显式实例化语法
   template class ClassName<TypeParameter>;

4. 必须包含实现文件
   #include <pcl/filters/impl/voxel_grid.hpp>  // 不是 .h

5. 链接错误识别
   undefined reference to pcl::XXX<YourType>::YYY
   → 需要显式实例化 XXX<YourType>

错误1: 在头文件中实例化

  template class pcl::VoxelGrid<pcl::PointXYZRGBL>;  // ❌
  
  后果: 多个 cpp 包含该头文件 → 重复定义错误

错误2: 忘记包含实现文件
  #include <pcl/filters/voxel_grid.h>  // ✓ 有声明
  // 缺少: #include <pcl/filters/impl/voxel_grid.hpp>  // ❌ 缺实现
  template class pcl::VoxelGrid<pcl::PointXYZRGBL>;
  
  后果: 编译错误 - 找不到模板定义

错误3: 使用PCL_INSTANTIATE宏
  PCL_INSTANTIATE(VoxelGrid, pcl::PointXYZRGBL)  // ❌ 不稳定
  
  后果: 可能出现 BOOST_PP_IIF_0 错误
