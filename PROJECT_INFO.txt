🚀 快速开始 (3步)

1. 准备数据
   cp /your/path/*_left.jpg data/input/
   cp /your/path/*_right.jpg data/input/

2. 编译
   ./build.sh

3. 运行
   ./run.sh

或者直接测试演示：
   ./test_demo.sh

✨ 核心功能

✅ 无ROS2依赖          - 仅需OpenCV + PCL + Eigen3
✅ 批量处理            - 自动处理文件夹中的所有图像对
✅ 点云三视图          - XY/XZ/YZ三个视角投影
✅ 多格式输出          - PCD、深度图、标签图、可视化图像
✅ 详细性能日志        - 每步耗时统计
✅ 易于调试            - 标准C++，GDB友好

🔧 依赖项

必需:
  • OpenCV 4.x       - 图像处理和立体视觉
  • PCL 1.10+        - 点云处理
  • Eigen3           - 线性代数
  • C++17编译器      - GCC 7+ 或 Clang 5+

安装命令 (Ubuntu/Debian):
  sudo apt install libopencv-dev libpcl-dev libeigen3-dev
